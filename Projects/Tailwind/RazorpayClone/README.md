# Razorpay UI Clone

A frontend UI project built to practice layout, responsiveness, and rapid styling using **Tailwind CSS**.  
The goal of this project was not originality, but to understand how utility-first CSS behaves in real-world layouts and how it compares to writing vanilla CSS.

---

## 🚀 Features

- Responsive layout
- Utility-first styling with Tailwind CSS
- Clean and minimal UI
- Fast iteration without switching between CSS files

---

## 🛠️ Tech Stack

- HTML 
- Tailwind CSS  

---

## 📚 What I Learned

This project helped me understand several practical aspects of frontend development:

- Tailwind CSS significantly speeds up development compared to writing vanilla CSS
- Readability can suffer when too many utility classes are used together
- Debugging layout issues in utility-first CSS requires a different mindset
- Knowing **when not to use Tailwind** is as important as knowing how to use it

---

## ⚖️ Trade-offs Observed

**Pros**
- Very fast prototyping
- No context switching between files
- Consistent spacing and design

**Cons**
- Class-heavy markup reduces readability
- Debugging complex layouts can be difficult
- Styling logic is harder to reason about at a glance

---

## 📌 Notes

This project was built as a learning exercise.
Future improvements may include:

- Mixing Tailwind with custom CSS where appropriate
- Improving layout positioning
